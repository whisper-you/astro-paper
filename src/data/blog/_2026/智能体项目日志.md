## 低代码派

**低代码（Low-Code）的核心本质就是：可视化界面 + 组件化封装。**

**高级用法：**

1. **架构设计能力**：你知道该选哪些组件，怎么组合才能解决复杂问题（比如：怎么处理错误？怎么优化成本？怎么保证数据一致性？）。
2. **业务理解能力**：你能把模糊的业务需求（“帮我收集 GitHub 项目”）拆解成具体的技术流程（搜索→过滤→总结→格式化）。
3. **调试与优化**：当流程跑不通时，你能通过日志定位是哪个组件出了问题，是参数错了还是逻辑断了。

## Web开发框架

| **框架**      | **核心优势**        | **建议使用场景**            |
| ----------- | --------------- | --------------------- |
| **Astro**   | 极速、群岛架构、多框架支持   | **个人博客**、内容类网站。       |
| **Next.js** | 生态无敌、全栈、SSR 强大  | **企业级 AI 应用**、复杂交互平台。 |
| **Gatsby**  | GraphQL 驱动、插件丰富 | **大型文档系统**、数据密集型静态站。  |
| **Remix**   | 动态性能强、标准 Web 开发 | **电商网站**、强交互的全栈项目。    |

| **特性**     | **Astro (群岛架构)** | **Next.js (全栈混合)**     | **Gatsby (数据驱动)**    |
| ---------- | ---------------- | ---------------------- | -------------------- |
| **主要目标**   | 性能、内容驱动          | 复杂应用、全栈                | 结构化内容、插件驱动           |
| **首选渲染方式** | **SSG** (静态优先)   | **SSR/ISR** (实时/混合)    | **SSG** (静态)         |
| **JS 消耗**  | **极低** (仅按需加载)   | **中/高** (默认整包)         | **中** (依赖 React 运行时) |
| **后端能力**   | 较弱（需外接 API）      | **极强** (内置 Serverless) | 较弱                   |

| **框架类型**        | **核心代表**               | **它是怎么工作的？**                          | **比喻**                            |
| --------------- | ---------------------- | ------------------------------------- | --------------------------------- |
| **静态生成 (SSG)**  | **Astro**, **Gatsby**  | 在你写完代码“构建”的那一刻，把所有网页都画好变成 `.html` 文件。 | **预制菜**：客人（用户）来之前就做好了，直接上菜，速度最快。  |
| **服务器渲染 (SSR)** | **Next.js**, **Remix** | 用户点一下链接，服务器才现场跑代码生成网页发给用户。            | **现点现做**：能根据用户的身份（比如登录状态）提供不同的内容。 |
| **单页应用 (SPA)**  | **纯 React (Vite)**     | 网页其实是个空壳，JavaScript 在用户的浏览器里现场“画图”。   | **自助餐**：给你餐具，你自己去夹菜（请求数据）拼凑。      |
